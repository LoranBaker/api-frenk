REST API for Frank — a CBT-inspired daily companion app. Built with .NET/C#, PostgreSQL (Supabase), and Claude AI integration.

.NET/C# REST API powering the Frank daily companion app. Handles all business logic, data persistence, and AI integration for a habit and urge management system built around CBT-inspired pattern awareness.
What it does:

Full check-in flow endpoints: morning reflection, urge-interrupt (HALT framework with intensity-based routing), evening check-in, and weekly mirror
Claude AI integration for context-aware interventions and weekly pattern summaries
DB-driven content system — all user-facing questions and content are stored in the database, enabling zero-deploy updates
Fully decoupled from the React Native frontend via REST

Stack: .NET/C#, PostgreSQL, Supabase, Claude AI (Anthropic API)
